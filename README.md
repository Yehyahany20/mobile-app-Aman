# 🛡️ Aman (أمان) - AI Arabic Vishing & Phishing Scam Detection App

<p align="center">
  <b>نظام الذكاء الاصطناعي لرصد مكالمات الاحتيال الصوتي باللهجات العربية</b><br>
  Based on the <b>DAMSE Framework</b> (AraBERT, mDeBERTa, SetFit, GBM & Dialect-Aware Ensemble)
</p>

## 🚀 المميزات الرئيسية للتطبيق
- **إطار عمل DAMSE:** يدمج 5 استراتيجيات ذكاء اصطناعي مختلفة لاستخراج الأدلة اللغوية وهندسة المخاطر.
- **تغطية شاملة للهجات:** مدرّب ومختبر على أكثر من 9 لهجات عربية (مصرية، خليجية، أردنية، شامية، سعودية، عراقية، سودانية، يمنية، والفصحى).
- **واجهة مستخدم احترافية:** مبنية باستخدام Flutter بتصميم Material 3 ودعم كامل وشامل للاتجاه من اليمين لليسار (RTL) مع خط Cairo العربي.
- **تفصيل دقيق لمؤشرات الخطر:** يوضح التطبيق نسبة الخطورة مع درجات الضغط المالي، الإلحاح، التهديد، وانتحال الصفة.

## 📁 هيكل المشروع
```text
lib/
├── core/
│   ├── constants/    # نصوص التطبيق باللغة العربية
│   └── theme/        # نظام الألوان والسمات (Light / Dark)
├── data/
│   ├── models/       # نماذج البيانات (AnalysisResult)
│   ├── providers/    # إدارة الحالة (Provider)
│   └── services/     # محاكي خوارزميات DAMSE
└── features/
    ├── splash/       # شاشة البداية المتحركة
    ├── onboarding/   # دليل التعريف بالتطبيق
    ├── home/         # الشاشة الرئيسية وحالة الحماية
    ├── analysis/     # شاشات فحص النصوص والنتائج
    ├── history/      # سجل التحليلات السابقة
    ├── statistics/   # إحصائيات البيانات ونماذج التدريب
    └── settings/     # الإعدادات وفريق العمل
```
